# Sound credits

All sounds sourced from Freesound.org, all CC0 (public domain). No sounds from the Family Feud TV show. Each file was trimmed (leading and/or trailing silence cut, short fade-out added where the original tail was abrupt) and gain-adjusted with ffmpeg so RMS loudness sits in roughly the same range across files (about -13 to -23 dB RMS, true peak kept at or below -0.85 dB, verified with `ffmpeg -af astats`), then re-encoded as mono 44.1 kHz 128 kbps MP3. No other processing.
